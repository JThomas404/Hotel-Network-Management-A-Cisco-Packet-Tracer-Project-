## Overview

This project presents a comprehensive network design solution for the Vic Modern Hotel, implementing enterprise-grade networking infrastructure using Cisco Packet Tracer. The design revolutionises hotel management technology through strategic implementation of VLANs, OSPF routing, and wireless connectivity across three floors.

## Design Overview

The network architecture meticulously connects departmental operations across three floors into a cohesive framework. The design links Reception, Store, and Logistics departments on the ground floor; Finance, HR, and Sales/Marketing on the first floor; and IT and Admin on the second floor, ensuring seamless inter-departmental communication whilst maintaining security boundaries.

---

## Hotel Network Highlights

### Floor Distribution
- **Ground Floor**: Reception, Store, Logistics
- **First Floor**: Finance, HR, Sales/Marketing  
- **Second Floor**: IT, Admin

### Infrastructure Placement
All routing equipment is centralised within the IT department's server room, providing optimal network management and security oversight.

---

## Networking Strategy

### VLAN Segmentation
Each department operates within its dedicated VLAN for enhanced security and efficient communication:
- **Reception**: VLAN 80 (192.168.8.0/24)
- **IT Department**: VLAN 10 (192.168.1.0/24)
- Additional VLANs configured per departmental requirements

### Wireless Integration
Dedicated switches on each floor extend connectivity to WiFi networks, ensuring comprehensive wireless coverage for laptops and mobile devices throughout the hotel premises.

---

## Routing and Connectivity

### Router Configuration
- **Three routers per floor** positioned in the IT server room
- **Serial DCE cables** provide robust intra-network communication
- **OSPF routing protocol** spans designated network segments:
  - 10.10.10.0/30
  - 10.10.10.4/30
  - 10.10.10.8/30

### Inter-VLAN Routing
Implemented to facilitate secure communication between departments whilst maintaining network segmentation.

---

## Dynamic IP Allocation

**OSPF Protocol** facilitates dynamic route advertising across the network infrastructure. **DHCP services** configured on routers provide automatic IP address assignment, ensuring seamless device connectivity without manual configuration requirements.
